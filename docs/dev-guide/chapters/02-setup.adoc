=== First-time setup

Every new PowerShell session starts with:

[source,powershell]
----
cd D:\dev\claude\LF\lf-capa
. .\local\env.ps1          # JAVA_HOME, kind provider, versions
----

Then, once:

[source,powershell]
----
.\local\00-prereqs.ps1 -Install   # installs kind, kubectl, argocd if missing
.\local\00-prereqs.ps1            # verify: everything [ok]
.\local\01-podman-rootful.ps1   # rootful machine
.\local\02-create-cluster.ps1   # kind cluster "capa" + Windows bridge
.\local\03-install-argocd.ps1   # Argo CD, prints the admin password
----

After a reboot (Windows or Podman machine), run `.\local\bridge.ps1` once.
Whenever something looks wrong: `.\local\status.ps1` -- one green/red line per component, with the fix.

.Done when
* [ ] `kubectl get nodes` shows one `Ready` node
* [ ] `kubectl get pods -n argocd` shows every pod `Running`
* [ ] https://localhost:30443 opens the Argo CD login page
