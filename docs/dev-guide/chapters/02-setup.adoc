=== First-time setup

Every new PowerShell session starts with:

[source,powershell]
----
cd D:\dev\claude\LF\lf-capa
. .\local\env.ps1          # JAVA_HOME, kind provider, versions
----

Then, once:

[source,powershell]
----
.\local\01-podman-rootful.ps1   # rootful machine, 4 CPU / 8 GB
.\local\02-create-cluster.ps1   # kind cluster "capa"
.\local\03-install-argocd.ps1   # Argo CD, prints the admin password
----

.Done when
* [ ] `kubectl get nodes` shows one `Ready` node
* [ ] `kubectl get pods -n argocd` shows every pod `Running`
* [ ] https://localhost:30443 opens the Argo CD login page
